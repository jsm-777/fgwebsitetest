# Financial Groove website redesign

Production-ready frontend for the Financial Groove website, built with Next.js 16, React 19, TypeScript, and the App Router.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run lint
npm run build
```

## Vercel

Import this GitHub repository into Vercel. The standard Next.js framework preset is sufficient; there are no required environment variables or backend services in this frontend release.

Before assigning `financialgroove.com`, review the content decisions in the adjacent workspace planning package at `CODEX_OUTPUT/FG_WEBSITE_REDESIGN_PLAN_2026-10-21`, especially current offer terms, photography rights, analytics/privacy requirements, and DNS/redirect ownership.

## Content boundaries

- Public pricing is intentionally omitted because source documents conflict.
- The Overture page directs visitors to ask for current terms.
- The live Las Vegas contact information is used; an unverified New York office claim is omitted.
- No attributed testimonial or press-logo claim is published without explicit reuse approval.
- Sensitive documents are routed to the existing ShareFile portal.
